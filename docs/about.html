About this project

An independent, append-only archive of Rowan University's Clery Act daily crime log, captured every day and kept after the university takes it down.

What this is

Why it exists

Rowan publishes the daily crime log as monthly Google Sheets in a public Drive folder. That folder is a working directory, not an archive: it holds a rolling window. Rowan's annual security report states that logs "for the most recent 90-day period are available for public inspection"; in practice the folder has held a little more. Either way, older months come down. Records are also edited after publication — the sheet marks that a disposition or an offense classification changed, but never what it said before, or when.

This project captures the log daily, keeps every version of every record, and logs each change it observes. TK — add the reporting rationale.

How it works

Each run fetches every monthly sheet, stores a byte-exact copy, and merges it into a permanent record. Nothing is ever deleted or overwritten: when a row changes, the change is recorded against the same incident; when a row or a whole month disappears from the source, it stays here, flagged. A record is only ever marked missing after it has been absent on three separate days, so a failed fetch is never mistaken for a deletion.

Offense and disposition wording is mapped to consistent categories through a checked-in file that anyone can read and audit. An unrecognised term stops the build rather than being quietly bucketed into "Other".

The full method — identity keying, the safety interlocks, known errors in the source and the limits of what these numbers can support — is in METHODOLOGY.md in the project repository.

How to use it responsibly

These are counts of logged incidents, not of crime. Reporting rates, Campus Security Authority referrals and the academic calendar all move them independently of anything happening on campus. Not every case number is a Rowan police matter — some are Glassboro municipal police, some are CSA reports with no police response.
